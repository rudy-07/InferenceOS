## 🎯 Optimization Recommendations

### 1. Offload Layer 20 to GPU
- 🔴 **[CRITICAL]** **Bottleneck**: GPU idle 98% (waiting on CPU layer computation)
- 🛠️ **Recommended Action**: `Move Layer 20 to GPU (--gpu-layers 21)`
- 📈 **Estimated Improvement**: **`+34.4% tok/s`**

### 2. Utilize Unused VRAM (6.0 GB Free)
- 🟡 **[WARNING]** **Bottleneck**: 6144 MB VRAM unallocated while 8 layers execute on CPU
- 🛠️ **Recommended Action**: `Increase GPU layer offload count to 28`
- 📈 **Estimated Improvement**: **`+28.0% tok/s`**

### 3. Enable Phase 8 Async Prefetching
- 🔵 **[INFO]** **Bottleneck**: Synchronous layer boundary transfer stalls GPU execution
- 🛠️ **Recommended Action**: `Set enable_async_scheduler=True and prefetch_lookahead=1`
- 📈 **Estimated Improvement**: **`+8.0% tok/s (overlaps transfer with compute)`**
