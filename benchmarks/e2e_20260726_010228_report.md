## 🎯 Optimization Recommendations

### 1. Utilize Unused VRAM (6.0 GB Free)
- 🟡 **[WARNING]** **Bottleneck**: 6144 MB VRAM unallocated while 16 layers execute on CPU
- 🛠️ **Recommended Action**: `Increase GPU layer offload count to 36`
- 📈 **Estimated Improvement**: **`+56.0% tok/s`**

### 2. Offload Layer 20 to GPU
- 🔴 **[CRITICAL]** **Bottleneck**: GPU idle 100% (waiting on CPU layer computation)
- 🛠️ **Recommended Action**: `Move Layer 20 to GPU (--gpu-layers 21)`
- 📈 **Estimated Improvement**: **`+35.0% tok/s`**

### 3. Enable Phase 8 Async Prefetching
- 🔵 **[INFO]** **Bottleneck**: Synchronous layer boundary transfer stalls GPU execution
- 🛠️ **Recommended Action**: `Set enable_async_scheduler=True and prefetch_lookahead=1`
- 📈 **Estimated Improvement**: **`+8.0% tok/s (overlaps transfer with compute)`**
